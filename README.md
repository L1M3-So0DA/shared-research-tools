# shared-research-tools
实验室学术研究辅助工具集，包含通用自动化脚本、SKILL 程序库及标准化技术文档。
## 仓库概述 (Repository Overview)

本仓库用于托管与维护实验室在学术研究过程中沉淀的通用型计算及开发资产。仓库内容独立于特定研究课题，侧重于科研工作流的自动化与规范化。主要包含以下功能模块：
- docs 团队分享文档与规范
- scripts 通用自动化与数据处理脚本
- skill 常用skill集合
